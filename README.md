# Aiman Ali – Portfolio (React + Vite + Tailwind CSS)
    npm install
    npm run dev      # local preview
    npm run build    # production build in /dist
- Contact details, social links, services, education and gallery items: `src/data.js`
- Images: `public/images/` (add a file, then add a row in `projects` in `src/data.js`)
- Colors / fonts: `tailwind.config.js`
- Pages: src/pages/Pages.jsx (Home, About, Services, Portfolio, Contact) — uses HashRouter so it works on any static host
